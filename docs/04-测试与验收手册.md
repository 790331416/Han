## 6. Playwright 规则

### 6.1 目录

```text
han-ui/
  tests/e2e/
  output/playwright/
```

### 6.2 当前推荐执行方式

当前仓库环境里，`pnpm test:e2e` 实际会落到错误的 `playwright` 二进制，不能稳定执行 `@playwright/test`。

当前有效执行方式是直接调用 `@playwright/test` CLI：

```powershell
cd han-ui
$env:PW_BASE_URL='http://10.18.35.95:3100'
$env:PW_API_URL='http://10.18.35.95:19090'
$env:PW_WORKERS='1'
node node_modules\.pnpm\@playwright+test@1.58.2\node_modules\@playwright\test\cli.js test
```

### 6.3 关键约束

- 默认使用 `PW_WORKERS=1`
- 每个 spec 使用独立 `--output` 目录
- 页面级健康回归必须捕获：
  - `HTTP 4xx/5xx`
  - 业务 `code != 200`
  - `requestfailed`
  - `pageerror`
  - `console error`
