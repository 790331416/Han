## 6. Playwright 规则

### 6.1 目录与职责

```text
han-ui/
  tests/e2e/                  # Han 通用后台与三档页面回归
  output/playwright/

han-aivideo-ui/
  tests/e2e/specs/
    aivideo-entry-admin.spec.ts
    aivideo-text-workflow.spec.ts
    aivideo-reference-images.spec.ts
    aivideo-media-workflow.spec.ts
    aivideo-remote-smoke.spec.ts
  output/playwright/
```

`han-aivideo-ui` 的前四类测试使用受控路由和数据模拟覆盖正常、边界、错误及恢复路径；`aivideo-remote-smoke.spec.ts` 只在显式开启远程门禁后连接真实 95。Mock 通过不能替代真实后端、数据库、文件和异步任务验证。

### 6.3 95 真实同会话回归

真实用例必须先验证登录页控件可见，再在同一浏览器上下文注入受控短期令牌；禁止把账号、密码或长期令牌写入仓库。

```powershell

.\node_modules\.bin\playwright.CMD test `
  tests/e2e/specs/aivideo-remote-smoke.spec.ts `
  --project=chromium --reporter=list
```

远程用例被 skip、令牌过期、项目不存在或只打开页面未执行断言，都不能记为“95 浏览器回归通过”。

### 6.4 全局错误监控

页面级回归必须捕获并分类：

- 非预期 `HTTP 4xx/5xx`。
- 业务 `code != 200`。
- `requestfailed`。
- `pageerror`。
- 非预期 `console error`。
- 登录失效、越权、租户错配和静默失败。

预期错误必须有明确断言和用户可见反馈，不能为了全绿而统一忽略。
