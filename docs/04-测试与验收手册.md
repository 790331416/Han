## 6. Playwright 规范

### 6.1 目录

```text
han-ui/
  tests/e2e/
  output/playwright/
```

### 6.2 推荐执行

```bash
cd han-ui
pnpm build
pnpm test:e2e
```

### 6.3 关键约束

- 默认使用 `PW_WORKERS=1`
- 每个 spec 建议使用独立输出目录，避免 artifact 冲突
- 页面级健康回归必须捕获 HTTP 错误、业务错误、页面异常和控制台异常
