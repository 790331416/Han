# 仓库结构治理规则

## 1. 正式入口

- 正式文档：`docs/`
- 正式 SQL：`sql/`
- 正式部署：`deploy/`
- 正式结构检查：`scripts/checks/`

## 2. 根目录白名单

根目录只允许保留以下类型内容：

- 构建入口：如 `pom.xml`、`build.sh`
- 稳定配置：如 `.gitignore`、`.gitattributes`
- 工程模块目录：如 `han-auth`、`han-modules`
- 顶层说明：`README.md`
- 正式根目录：`docs`、`sql`、`deploy`、`scripts`

## 3. 禁止项

- 新增根目录散装文档
- 新增根目录散装 SQL
- 新增根目录散装部署文件
- 新增根目录散装验证输出
- 在 `doc/` 中新增正式文档
- 在根目录保留临时研究副本或历史打包产物

## 4. 迁移要求

- 老资料在迁移完成前可短期保留，但必须有归档计划
- 正式文档重构后，旧入口必须在本轮整理中退役
- 任意结构级变更必须同步更新 `docs/index.md`
- 已被新结构吸收的旧 SQL、旧文档和旧部署说明必须迁入归档或删除，不得继续占据主视图
