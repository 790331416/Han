# 95部署与清理规则

## 1. 正式目录

95 上只保留以下正式目录：

- `/opt/han/repo/Han`
- `/opt/han/deploy/small`
- `/opt/han/deploy/medium`
- `/opt/han/deploy/full`
- `/opt/han/backups/pre-rebuild/<timestamp>`
- `/opt/han/logs`
- `/opt/han/archive`

## 2. 禁止项

- 禁止在 `/opt/han/source` 下继续堆新的 `Han-*` 验证目录
- 禁止继续使用 `/opt/han/docker` 作为正式部署主入口
- 禁止通过手工上传 `jar`、`dist` 替代服务端构建
- 禁止在 95 上保留无说明的 canary/live 混合目录

## 3. 清理原则

- 清理前先备份必要 secrets
- 清理旧 Han 容器、镜像、网络、volume
- 清理旧源码目录与旧部署目录
- 清理后按三档正式目录重建

## 4. 验证要求

- 每次重建后至少验证 `small / medium / full` 的运行时能力
- 发布结果必须回填到 `docs/03-测试/95验证运行手册.md`
