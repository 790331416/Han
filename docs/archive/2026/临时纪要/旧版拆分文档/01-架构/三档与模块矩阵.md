# 三档与模块矩阵

| 模块 | small | medium | full |
| --- | --- | --- | --- |
| gateway | 是 | 是 | 是 |
| auth | 是 | 是 | 是 |
| system | 是 | 是 | 是 |
| job | 是 | 是 | 是 |
| tenant | 否 | 是 | 是 |
| workflow | 否 | 是 | 是 |
| open | 否 | 是 | 是 |
| file | 否 | 是 | 是 |
| ai | 否 | 否 | 是 |
| gen | 否 | 否 | 是 |

## 说明

- `medium` 继承 `small`
- `full` 继承 `medium`
- 前端菜单与登录页应以运行时能力为准，而不是仅凭静态路由判断
