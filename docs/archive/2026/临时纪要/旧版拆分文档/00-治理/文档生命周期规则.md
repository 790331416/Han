# 文档生命周期规则

## 1. 分类

- 正式文档：当前仍有效、仍需维护
- 归档文档：历史记录、一次性排障、阶段性报告
- 废弃文档：已完全失效且不再需要保留

## 2. 落位

- 正式文档进入 `docs/<分类>/`
- 归档文档进入 `docs/归档/<年份>/<子类>/`
- 废弃文档在确认无保留价值后删除

## 3. 命名

- 正式分类目录和正式文档文件名统一使用中文
- 归档文档可保留原文件名，也可做中文化重命名
- 同一主题仅保留一份正式入口

## 4. 维护义务

- 新增正式文档必须入索引
- 正式文档变更时应同步更新相关规则和导航
- 迁移旧文档后，原入口必须退役或归档
