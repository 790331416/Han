# Han 手测 Checklist（2026-04-07）

## 1. 目的

这份清单只覆盖当前已经在 `95` 真环境中真实通过的功能，方便按 `small / medium / full` 三档做人工复核。

执行口径：

- 只测已通过能力，不把未开发项混进来
- 按档位逐层验证，`medium` 继承 `small`，`full` 继承 `medium`
- 遇到环境异常先记录，不直接判业务失败

## 2. 环境入口

- `small`：`http://10.18.35.95:3100`
- `medium`：`http://10.18.35.95:3200`
- `full`：`http://10.18.35.95:3000`
- 默认账号：`admin / admin123`

建议先确认：

- 页面能正常打开，不是 `502` 或白屏
- 登录页验证码正常加载
- 登录后不弹全局异常 toast

## 8. 建议测试顺序

建议按下面顺序执行，出问题时更容易定位：

1. `small`：登录 -> 通知中心 -> 任务调度
2. `medium`：租户 -> 开放平台 -> OSS 上传
3. `full`：代码生成 -> AI 模型 -> 知识库 -> Prompt -> MCP -> AI 对话

## 9. 备注

如果手测过程中出现以下现象，优先按环境问题记录：

- 登录页能开，但登录后整页 `502`
- 页面可进，但所有接口同时报错
- OSS 返回内网地址
- AI 模型突然全部显示“未配置”
- 未开发路由出现白屏而不是 `404`
