# AI 短剧文档目录

本目录保存 AIVideo / AI 短剧已确认并进入 Han 开发流的正式设计与计划文档。

`D:\code\AIVideo` 仍作为规划区、参考材料区、提示词资产区和环境信息留存区；本目录只同步会直接指导 Han 代码、SQL、前端、联调和验收的确认版文档。

## 使用规则

- 进入 AI 短剧代码实现前，先读 [../08-AI短剧开发手册.md](../08-AI短剧开发手册.md)，再读本目录相关文档。
- 本目录文档必须与 Han 代码、SQL、前端和验证同步维护。
- 不在本目录保存完整 API Key、数据库密码、Redis 密码、测试账号明文或客户原文。
- 草稿、参考 TXT、提示词原件、环境敏感信息继续留在 `D:\code\AIVideo` 的对应目录。
