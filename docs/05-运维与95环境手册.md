# 运维与95环境手册

## 1. 95 正式目录

- `/opt/han/repo/Han`
- `/opt/han/deploy/small`
- `/opt/han/deploy/medium`
- `/opt/han/deploy/full`
- `/opt/han/backups/pre-rebuild/<timestamp>`
- `/opt/han/logs`
- `/opt/han/archive`

## 2. 95 固定发布链路

1. 从 `master` 拉代码
2. 在 95 本机完成构建
3. 用正式部署目录执行 compose
4. 跑固定验证清单

## 3. 95 禁止项

- 继续使用 `/opt/han/source/Han-*` 目录发布
- 继续用 `/opt/han/docker` 作为正式入口
- 手工上传 `jar` 或 `dist`
- 保留无说明的 canary/live 混合目录

## 4. Nacos 配置说明

### 4.1 正式位置

- 共享模板：
- `jobflow-scheduler` 配置已经并入各档 Nacos 导入 SQL
- tier 导入脚本：
  - `sql/tiers/small/small-nacos-derby-import.sql`
  - `sql/tiers/medium/medium-nacos-derby-import.sql`
  - `sql/tiers/full/full-nacos-derby-import.sql`

### 4.2 原则

- Nacos 导入脚本与 PostgreSQL 初始化脚本分开管理
- tier 专用配置不得散落在 `sql/` 根目录
- 95 导入前先备份原始 Derby 数据目录

## 5. PostgreSQL 初始化与升级

### 5.1 通用顺序

1. 初始化 tier SQL
2. 执行 tier 对应 Nacos 导入
3. 执行必要的升级脚本
4. 拉起服务后验证运行时能力

### 5.2 tier 口径

- `small`：system、job
- `medium`：在 `small` 基础上增加 tenant、workflow、open、file
- `full`：在 `medium` 基础上增加 ai、gen

## 7. 环境清理手册

### 7.1 仓库清理

- 清理构建产物
- 清理缓存目录
- 清理临时验证文件
- 清理无用分支

### 7.2 95 清理

1. 备份必要 secrets
2. 停止并删除 Han 相关容器
3. 清理旧镜像、旧网络、旧 volume
4. 清理旧源码目录和旧部署目录
5. 按新目录重建

## 8. 常见排障顺序

1. PostgreSQL
2. Redis
3. Nacos
4. Gateway
5. 核心业务服务
6. UI
7. 页面级健康回归

## 9. 运维留痕要求

- 发布前记录来源提交
- 发布后记录运行态与验证结果
- 出现问题记录故障时间、影响范围、恢复动作
- 所有一次性故障文档进入 `docs/archive/`
