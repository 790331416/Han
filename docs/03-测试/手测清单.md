# 手测清单

## small

1. 登录并进入首页
2. 打开通知中心，检查未读数、单条已读、全部已读
3. 打开任务调度列表和日志页，执行一次新增与立即执行
4. 检查系统管理与日志监控核心页面可达

## medium

1. 在 `small` 清单基础上继续
2. 打开租户、租户套餐、租户配额
3. 打开开放平台并验证应用生命周期操作
4. 打开 OSS 配置并执行真实上传
5. 打开工作流定义、实例、待办、已办

## full

1. 在 `medium` 清单基础上继续
2. 打开代码生成，验证导入、预览、下载
3. 打开 AI 模型，检查配置与连通测试
4. 打开知识库、Prompt、MCP、应用、聊天、Token 页面
5. 验证应用详情、结构化元数据和聊天链路
