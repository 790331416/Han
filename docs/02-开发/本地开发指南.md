# 本地开发指南

## 基础环境

- JDK 21
- Maven 3.9+
- Node.js 18+
- Docker 26+
- Docker Compose 2.x

## 推荐命令

```powershell
mvn -gs settings.workspace.xml -DskipTests compile
```

```powershell
cd han-ui
pnpm install
pnpm build
```

## 开发要求

- 文档、SQL、部署结构变更必须同步更新正式文档
- 前端变更不得依赖仓库中的历史 `dist`
- 本地验证优先使用正式 compose 和正式测试脚本
