## 三、优先级排序 — 建议补齐的功能

### P0（核心缺失，影响基本可用性）

1. **动态菜单路由** — 后端返回菜单树，前端动态生成路由。当前前端硬编码路由，新增菜单需改前端代码。
2. **数据权限完善** — 支持"全部/自定义部门/本部门/本部门及以下/仅本人"5种策略。
3. **在线用户管理** — 查看在线用户列表，支持强制退出。
4. **代码生成器** — 根据数据库表自动生成 CRUD 代码（Controller/Service/Mapper/Vue页面）。

### P1（体验提升，竞品标配）

5. **Redis 多租户隔离** — key 加 tenant 前缀，防止跨租户数据污染。
6. **文件管理完善** — 支持本地/MinIO/阿里云OSS/七牛云等多存储后端。
7. **可视化流程设计器** — BPMN 拖拽设计流程图。
8. **租户域名绑定** — 支持租户自定义域名访问。

### P2（锦上添花）

9. **短信/邮件管理** — 多渠道短信发送、邮件模板管理。
10. **三方登录** — 微信、钉钉、企业微信等社交登录。
11. **数据库隔离模式** — 支持每个租户独立数据库。
12. **表单构建器** — 可视化拖拽生成表单。

## 四、Han Cloud 独有优势

| 优势 | 说明 |
|------|------|
| **技术栈最新** | Spring Boot 4.0 + JDK 21 + Virtual Threads，领先竞品 2-3 个大版本 |
| **AI 能力** | 内置 AI 模型管理、知识库、MCP、智能体、AI工作流、Prompt模板等 |
| **开放平台** | OAuth2 应用管理和 API 开放能力 |
| **租户配额** | 精细化的资源配额管理（用户数/存储/API调用量等） |
| **AIB 架构** | Admin/Inner/Base 三层控制器架构，代码复用度高 |
| **@HttpExchange** | 替代 OpenFeign 的声明式客户端，无额外依赖 |
| **UnoCSS** | 原子化 CSS，替代传统 SCSS，开发效率更高 |

---

## 五、总结

Han Cloud 在**技术栈先进性**和 **AI 能力**上领先竞品，但在**多租户深度封装**（Redis/Job/MQ 隔离）、**动态菜单路由**、**代码生成**、**数据权限**等基础功能上存在差距。建议按 P0→P1→P2 优先级逐步补齐。
