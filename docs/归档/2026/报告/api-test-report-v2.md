## 部署修复记录

| 问题 | 原因 | 修复 |
|------|------|------|
| 登录 500 错误 | `UserVO.pwdUpdateTime` Jackson 3 反序列化失败 | 添加 `@JsonFormat(pattern="yyyy-MM-dd HH:mm:ss")` |
| 密码校验错误不友好 | `PasswordUtil.validate()` 抛 `IllegalArgumentException` | 改为抛 `BusinessException`，错误消息直接返回前端 |
