# Han Cloud 系统管理模块 — 前端功能测试指南

> **测试环境要求**
> - han-auth 服务运行在 `localhost:9200`
> - han-system 服务运行在 `localhost:9201`
> - 前端 dev server 运行在 `localhost:3000`（`pnpm dev`）
> - 默认管理员账号：`admin / admin123`

---

## 一、登录模块

### 1.1 验证码加载
- [ ] 打开 `http://localhost:3000`，自动跳转到登录页
- [ ] 验证码图片正常显示
- [ ] 点击验证码图片可刷新

### 1.2 登录
- [ ] 输入 `admin / admin123` + 正确验证码，点击登录
- [ ] 提示"登录成功"，自动跳转到首页 `/dashboard`
- [ ] 左侧菜单正常渲染（系统管理、工作流等）

### 1.3 登录失败
- [ ] 输入错误密码，提示错误信息
- [ ] 输入错误验证码，提示验证码错误
- [ ] 不输入用户名/密码，表单校验提示

---

## 二、菜单管理（系统管理 → 菜单管理）

### 2.1 菜单列表
- [ ] 进入菜单管理页面，树形表格正常显示
- [ ] 能看到目录（系统管理）、菜单（用户管理、角色管理等）、按钮（用户新增、用户修改等）三种类型
- [ ] 类型列分别显示蓝色"目录"、绿色"菜单"、橙色"按钮"标签

### 2.2 展开/折叠
- [ ] 点击"折叠"按钮，所有树节点收起
- [ ] 再点击"展开"按钮，所有树节点展开

### 2.3 搜索筛选
- [ ] 输入菜单名称搜索（如"用户"），列表只显示匹配项
- [ ] 选择状态筛选（正常/停用），列表正确过滤
- [ ] 点击"重置"恢复全部显示

### 2.4 新增菜单
- [ ] 点击顶部"新增菜单"按钮，弹窗打开
- [ ] 上级菜单默认"主目录"，可选择其他菜单作为父级
- [ ] 选择菜单类型为"目录"，填写名称和路由地址，提交成功
- [ ] 选择菜单类型为"菜单"，填写名称、路由地址、组件路径、权限标识，提交成功
- [ ] 选择菜单类型为"按钮"，填写名称和权限标识，提交成功
- [ ] 在某行的操作列点击"新增"，弹窗中上级菜单自动设为该行

### 2.5 编辑菜单
- [ ] 点击操作列"编辑"，弹窗回显所有字段
- [ ] 修改菜单名称，提交成功，列表刷新显示新名称

### 2.6 删除菜单
- [ ] 点击操作列"删除"，弹出确认框
- [ ] 确认删除后提示"删除成功"，列表刷新

## 三、部门管理（系统管理 → 部门管理）

### 3.1 部门列表
- [ ] 进入部门管理页面，树形表格正常显示
- [ ] 显示部门名称、负责人、联系电话、邮箱、排序、状态等列

### 3.2 新增部门
- [ ] 点击"新增部门"，弹窗打开
- [ ] 选择上级部门，填写部门名称、负责人等信息
- [ ] 提交成功，列表刷新

### 3.3 编辑部门
- [ ] 点击"编辑"，弹窗回显部门信息
- [ ] 修改部门名称，提交成功

### 3.4 删除部门
- [ ] 点击"删除"，确认后删除成功
- [ ] **注意**：有子部门的部门不能删除（后端会返回错误提示）

## 四、角色管理（系统管理 → 角色管理）

### 4.1 角色列表
- [ ] 进入角色管理页面，表格显示角色列表
- [ ] 显示角色ID、角色名称、权限字符、排序、状态、创建时间、操作列
- [ ] 超级管理员角色（ID=1）的编辑和删除按钮置灰

### 4.2 搜索筛选
- [ ] 输入角色名称搜索，列表过滤
- [ ] 输入权限字符搜索，列表过滤
- [ ] 选择状态筛选，列表过滤
- [ ] 点击"重置"恢复

### 4.3 新增角色（含菜单权限分配）
- [ ] 点击"新增角色"，弹窗打开
- [ ] 填写角色名称（如"测试角色"）、权限字符（如"test"）
- [ ] **菜单权限树**正常显示，包含所有菜单节点
- [ ] 勾选需要分配的菜单权限（如只勾选"用户管理"及其子按钮）
- [ ] 提交成功，列表刷新

### 4.4 编辑角色（验证菜单权限回显）
- [ ] 点击刚创建的角色的"编辑"按钮
- [ ] 弹窗回显角色基本信息
- [ ] **菜单权限树**中之前勾选的菜单节点已被选中 ✅
- [ ] 可以修改勾选状态（增加或取消菜单权限），提交成功

### 4.5 角色状态切换
- [ ] 在列表中切换角色状态开关（启用↔停用）
- [ ] 提示操作成功，状态更新

### 4.6 删除角色
- [ ] 点击"删除"，确认后删除成功
- [ ] **注意**：已分配给用户的角色不能删除

## 五、用户管理（系统管理 → 用户管理）

### 5.1 用户列表
- [ ] 进入用户管理页面，表格显示用户列表
- [ ] 显示用户ID、用户名、昵称、部门、手机号、状态、创建时间、操作列
- [ ] 分页器正常工作

### 5.2 搜索筛选
- [ ] 输入用户名搜索，列表过滤
- [ ] 输入手机号搜索，列表过滤
- [ ] 选择状态筛选，列表过滤
- [ ] 点击"重置"恢复

### 5.3 新增用户（含角色和部门分配）
- [ ] 点击"新增"，弹窗打开

- [ ] **部门选择器**：下拉树正常显示，选择一个部门
- [ ] **角色选择器**：下拉多选正常显示所有可用角色，选择一个或多个角色
- [ ] 填写手机号、邮箱（可选）
- [ ] 提交成功，列表刷新，新用户出现在列表中

### 5.4 编辑用户（验证角色和部门回显）

- [ ] 弹窗回显用户基本信息
- [ ] 用户名字段置灰不可修改
- [ ] **部门**回显为之前选择的部门 ✅
- [ ] **角色**回显为之前分配的角色 ✅
- [ ] 可修改角色分配和部门，提交成功

### 5.5 重置密码
- [ ] 点击操作列"重置"按钮
- [ ] 弹出密码输入框，输入新密码（6-20位）
- [ ] 确认后提示"重置成功"

### 5.6 用户状态切换
- [ ] 在列表中切换用户状态开关（启用↔停用）
- [ ] 弹出确认框，确认后提示操作成功

### 5.7 删除用户
- [ ] 点击"删除"，确认后删除成功
- [ ] 勾选多个用户，点击顶部"删除"按钮，批量删除成功

## 六、权限联动验证（核心流程）

> 此流程模拟完整的权限分配链路：创建菜单 → 创建角色并分配菜单 → 创建用户并分配角色 → 验证权限生效

### 6.1 准备：确认菜单数据
- [ ] 进入菜单管理，确认存在"用户管理"菜单及其子按钮（用户新增 `system:user:add`、用户修改 `system:user:edit` 等）

### 6.2 创建测试角色并分配菜单
- [ ] 进入角色管理，点击"新增角色"
- [ ] 角色名称：`测试角色`，权限字符：`tester`
- [ ] 在菜单权限树中勾选：系统管理 → 用户管理 → 用户新增、用户修改
- [ ] 提交成功

### 6.3 验证角色菜单回显
- [ ] 编辑刚创建的"测试角色"
- [ ] 确认菜单权限树中"用户新增"和"用户修改"已勾选
- [ ] 确认其他未分配的菜单未勾选

### 6.4 创建测试用户并分配角色
- [ ] 进入用户管理，点击"新增"
- [ ] 用户名：`tester01`，昵称：`测试员`
- [ ] 密码：`Test@12345`
- [ ] 部门：选择一个部门
- [ ] 角色：选择刚创建的"测试角色"
- [ ] 提交成功

### 6.5 验证用户角色回显
- [ ] 编辑刚创建的"tester01"用户
- [ ] 确认角色下拉中显示"测试角色"已选中
- [ ] 确认部门回显正确

### 6.6 清理测试数据
- [ ] 删除测试用户 `tester01`
- [ ] 删除测试角色 `测试角色`
