## 1. 部署方案选择

### 1.1 部署规模对比

根据您的使用场景，选择合适的部署规模：

| 规模 | 适用场景 | 硬件要求 | 中间件组合 | 部署文件 |
|------|----------|----------|-----------|----------|
| **小型（极简版）** | 个人开发/学习/演示 | 2核4GB | PostgreSQL + Redis + Nacos + RustFS | `docker-compose-small.yml` |
| **中型（标准版）** | 小团队/测试环境 | 4核8GB | + RabbitMQ | `docker-compose.yml` |
| **大型（企业版）** | 生产环境/大规模 | 8核16GB+ | + Kafka + Elasticsearch | Kubernetes 部署 |

### 1.2 组件依赖关系

```
核心组件 (必需)
├── PostgreSQL  - 主数据库
├── Redis       - 缓存 + 分布式锁
├── Nacos       - 服务注册 + 配置中心
└── RustFS      - 高性能对象存储 (S3 兼容)

标准组件 (中型部署)
└── RabbitMQ    - 异步消息队列

企业组件 (大型部署)
├── Kafka       - 大数据流处理
└── Elasticsearch - 日志聚合 + 搜索
```

## 2. Docker Compose 部署

### 2.1 小型部署（推荐入门）

**适合**: 个人学习、功能演示、快速验证

#### 步骤 1：准备环境

```bash
# 安装 Docker 和 Docker Compose
# Windows: 安装 Docker Desktop
# Linux: 
sudo apt update
sudo apt install docker.io docker-compose
```

#### 步骤 2：克隆项目

```bash
git clone <repository-url>
cd XuMan
```

#### 步骤 3：启动小型环境

```bash
# 启动所有服务
docker-compose -f docker-compose-small.yml up -d

# 查看服务状态
docker-compose -f docker-compose-small.yml ps

# 查看日志
docker-compose -f docker-compose-small.yml logs -f
```

#### 步骤 4：访问服务

等待 2-3 分钟服务完全启动后访问：

- **Nacos**: http://localhost:8848/nacos (xuman/xuman@2026)
- **网关**: http://localhost:8080
- **前端**: http://localhost:80

#### 包含服务

- ✅ PostgreSQL (数据库)
- ✅ Redis (缓存 + 分布式锁)
- ✅ Nacos (服务注册 + 配置中心)
- ✅ RustFS (对象存储)
- ✅ Gateway (网关)
- ✅ Auth (认证服务)
- ✅ System (系统管理)
- ✅ Job (JobFlow 任务调度)

#### 停止服务

```bash
# 停止所有服务
docker-compose -f docker-compose-small.yml down

# 停止并删除数据卷
docker-compose -f docker-compose-small.yml down -v
```

### 2.2 中型部署（推荐团队）

**适合**: 小团队开发、测试环境、完整功能验证

#### 步骤 1：启动中型环境

```bash
# 启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps
```

#### 额外包含服务

- ✅ RabbitMQ (异步消息队列)
- ✅ Tenant (租户管理)
- ✅ Workflow (工作流)
- ✅ Open (开放平台)

- **RustFS Console**: http://localhost:9001 (xumanadmin/xuman@2026)

### 2.3 Docker Compose 配置示例

#### docker-compose-small.yml 示例

```yaml
version: '3.8'

services:
  # PostgreSQL 数据库
  postgres:
    image: postgres:18.1
    container_name: xuman-postgres
    environment:
      POSTGRES_DB: xuman
      POSTGRES_USER: xuman
      POSTGRES_PASSWORD: xuman@2026
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./sql/postgres/init.sql:/docker-entrypoint-initdb.d/init.sql
    networks:
      - xuman-network

  # Redis 缓存
  redis:
    image: redis:7-alpine
    container_name: xuman-redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    networks:
      - xuman-network

  # Nacos 服务注册与配置中心
  nacos:
    image: nacos/nacos-server:v3.1.0
    container_name: xuman-nacos
    environment:
      MODE: standalone
      SPRING_DATASOURCE_PLATFORM: postgres
      NACOS_AUTH_ENABLE: true
    ports:
      - "8848:8848"
      - "9848:9848"
    depends_on:
      - postgres
    volumes:
      - nacos_data:/home/nacos/data
    networks:
      - xuman-network

  # RustFS 对象存储
  rustfs:
    image: rustfs/rustfs:latest
    container_name: xuman-rustfs
    environment:
      RUSTFS_ROOT_USER: xumanadmin
      RUSTFS_ROOT_PASSWORD: xuman@2026
    ports:
      - "9000:9000"  # API 端口
      - "9001:9001"  # Console 端口
    volumes:
      - rustfs_data:/data
    command: server /data --console-address ":9001"
    networks:
      - xuman-network

  # 网关服务
  gateway:
    image: xuman/gateway:latest
    container_name: xuman-gateway
    environment:
      SPRING_PROFILES_ACTIVE: docker
      NACOS_SERVER_ADDR: nacos:8848
    ports:
      - "8080:8080"
    depends_on:
      - nacos
      - redis
    networks:
      - xuman-network

  # 认证服务
  auth:
    image: xuman/auth:latest
    container_name: xuman-auth
    environment:
      SPRING_PROFILES_ACTIVE: docker
      NACOS_SERVER_ADDR: nacos:8848
    ports:
      - "9200:9200"
    depends_on:
      - nacos
      - postgres
      - redis
    networks:
      - xuman-network

  # 系统服务
  system:
    image: xuman/system:latest
    container_name: xuman-system
    environment:
      SPRING_PROFILES_ACTIVE: docker
      NACOS_SERVER_ADDR: nacos:8848
    ports:
      - "9201:9201"
    depends_on:
      - nacos
      - postgres
      - redis
    networks:
      - xuman-network

  # 任务调度服务
  job:
    image: xuman/job:latest
    container_name: xuman-job
    environment:
      SPRING_PROFILES_ACTIVE: docker
      NACOS_SERVER_ADDR: nacos:8848
    ports:
      - "9204:9204"
    depends_on:
      - nacos
      - postgres
      - redis
    networks:
      - xuman-network

volumes:
  postgres_data:
  redis_data:
  nacos_data:
  rustfs_data:

networks:
  xuman-network:
    driver: bridge
```

## 3. Kubernetes 部署

### 3.1 大型部署（生产环境）

**适合**: 生产环境、高可用、大规模用户

#### 前置条件

- Kubernetes 集群 (v1.25+)
- kubectl 命令行工具
- Helm 3.0+

#### 步骤 1：准备 Kubernetes 配置

```bash
# 创建命名空间
kubectl create namespace xuman-cloud

# 创建配置 ConfigMap
kubectl apply -f k8s/configmap.yaml -n xuman-cloud

# 创建密钥 Secret
kubectl apply -f k8s/secret.yaml -n xuman-cloud
```

#### 步骤 2：部署中间件

```bash
# 部署 PostgreSQL
helm install postgres bitnami/postgresql -n xuman-cloud \
  --set auth.username=xuman \
  --set auth.password=xuman@2026 \
  --set auth.database=xuman

# 部署 Redis
helm install redis bitnami/redis -n xuman-cloud \
  --set auth.enabled=false

# 部署 Nacos
helm install nacos nacos/nacos -n xuman-cloud \
  --set mode=cluster \
  --set replicaCount=3

# 部署 RustFS （对象存储）
helm install rustfs rustfs/rustfs -n xuman-cloud \
  --set auth.rootUser=xumanadmin \
  --set auth.rootPassword=xuman@2026 \
  --set persistence.size=100Gi
```

#### 步骤 3：部署业务服务

```bash
# 部署网关
kubectl apply -f k8s/gateway-deployment.yaml -n xuman-cloud

# 部署认证服务
kubectl apply -f k8s/auth-deployment.yaml -n xuman-cloud

# 部署系统服务
kubectl apply -f k8s/system-deployment.yaml -n xuman-cloud

# 部署其他业务模块
kubectl apply -f k8s/tenant-deployment.yaml -n xuman-cloud
kubectl apply -f k8s/workflow-deployment.yaml -n xuman-cloud
kubectl apply -f k8s/job-deployment.yaml -n xuman-cloud
```

#### 步骤 4：配置 Ingress

```bash
# 部署 Ingress
kubectl apply -f k8s/ingress.yaml -n xuman-cloud
```

#### Deployment 配置示例

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: xuman-gateway
  namespace: xuman-cloud
spec:
  replicas: 3
  selector:
    matchLabels:
      app: xuman-gateway
  template:
    metadata:
      labels:
        app: xuman-gateway
    spec:
      containers:
      - name: gateway
        image: xuman/gateway:latest
        ports:
        - containerPort: 8080
        env:
        - name: SPRING_PROFILES_ACTIVE
          value: "k8s"
        - name: NACOS_SERVER_ADDR
          value: "nacos-service:8848"
        resources:
          requests:
            memory: "512Mi"
            cpu: "500m"
          limits:
            memory: "1Gi"
            cpu: "1000m"
        livenessProbe:
          httpGet:
            path: /actuator/health
            port: 8080
          initialDelaySeconds: 60
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /actuator/health
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 5
---
apiVersion: v1
kind: Service
metadata:
  name: xuman-gateway-service
  namespace: xuman-cloud
spec:
  selector:
    app: xuman-gateway
  ports:
  - protocol: TCP
    port: 8080
    targetPort: 8080
  type: ClusterIP
```

### 3.2 Kubernetes 运维命令

```bash
# 查看所有 Pod
kubectl get pods -n xuman-cloud

# 查看服务状态
kubectl get svc -n xuman-cloud

# 查看日志
kubectl logs -f <pod-name> -n xuman-cloud

# 扩容/缩容
kubectl scale deployment xuman-gateway --replicas=5 -n xuman-cloud

# 更新镜像
kubectl set image deployment/xuman-gateway gateway=xuman/gateway:v2.0 -n xuman-cloud

# 重启服务
kubectl rollout restart deployment/xuman-gateway -n xuman-cloud

# 查看部署历史
kubectl rollout history deployment/xuman-gateway -n xuman-cloud

# 回滚
kubectl rollout undo deployment/xuman-gateway -n xuman-cloud
```

## 5. 配置说明

### 5.1 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `SPRING_PROFILES_ACTIVE` | 激活的配置文件 | `dev` |
| `NACOS_SERVER_ADDR` | Nacos 地址 | `localhost:8848` |
| `DB_HOST` | 数据库主机 | `localhost` |
| `DB_PORT` | 数据库端口 | `5432` |
| `DB_NAME` | 数据库名称 | `xuman` |
| `DB_USER` | 数据库用户 | `xuman` |
| `DB_PASSWORD` | 数据库密码 | `xuman@2026` |
| `REDIS_HOST` | Redis 主机 | `localhost` |
| `REDIS_PORT` | Redis 端口 | `6379` |

### 5.2 Nacos 配置

#### jobflow-scheduler.yml

```yaml
spring:
  jobflow:
    # JobFlow 自研任务调度框架配置
    scheduler-name: XumanScheduler
    cluster-mode: true
    thread-pool-size: 10
    persistence:
      type: jdbc
      driver-delegate: org.postgresql.Driver
```

### 5.3 数据库初始化

执行顺序：
1. `sql/xuman_system.sql` - 系统表
2. `sql/xuman_data.sql` - 初始数据
3. `sql/xuman_job.sql` - 任务表
4. `sql/xuman_workflow.sql` - 工作流表
5. `sql/xuman_open.sql` - 开放平台表

## 7. 故障排查

### 7.1 常见问题

#### 问题 1: 服务启动失败

**症状**: 容器启动后立即退出

**排查步骤**:
```bash
# 查看容器日志
docker logs <container-name>

# 查看容器状态
docker inspect <container-name>

# 检查环境变量
docker exec <container-name> env
```

**常见原因**:
- 数据库连接失败
- Nacos 配置未加载
- 端口被占用

#### 问题 2: 服务无法注册到 Nacos

**排查步骤**:
1. 检查 Nacos 是否正常运行
2. 检查网络连通性: `ping nacos`
3. 查看 Nacos 日志
4. 检查服务配置中的 Nacos 地址

#### 问题 3: 数据库连接失败

**排查步骤**:
```bash
# 测试数据库连接
docker exec -it xuman-postgres psql -U xuman -d xuman

# 检查数据库日志
docker logs xuman-postgres

# 检查数据库配置
docker exec xuman-postgres cat /var/lib/postgresql/data/postgresql.conf
```

#### 问题 4: Redis 连接失败

**排查步骤**:
```bash
# 测试 Redis 连接
docker exec -it xuman-redis redis-cli ping

# 检查 Redis 日志
docker logs xuman-redis
```

### 7.2 性能优化

#### JVM 参数调优

```bash
# 在 Dockerfile 或 docker-compose.yml 中设置
JAVA_OPTS=-Xms512m -Xmx1024m -XX:+UseG1GC -XX:MaxGCPauseMillis=200
```

#### 数据库连接池

```yaml
spring:
  datasource:
    hikari:
      minimum-idle: 5
      maximum-pool-size: 20
      connection-timeout: 30000
      idle-timeout: 600000
      max-lifetime: 1800000
```

### 7.3 应急处理

#### 服务重启

```bash
# Docker Compose
docker-compose restart <service-name>

# Kubernetes
kubectl rollout restart deployment/<deployment-name> -n xuman-cloud
```

#### 紧急回滚

```bash
# Kubernetes 回滚到上一个版本
kubectl rollout undo deployment/<deployment-name> -n xuman-cloud

# 回滚到指定版本
kubectl rollout undo deployment/<deployment-name> --to-revision=2 -n xuman-cloud
```
