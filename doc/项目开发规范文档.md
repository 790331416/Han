## 1. 技术栈强制约束

### 1.1 核心技术栈

| 技术组件 | 版本 | 用途 | 备注 |
|---------|------|------|------|
| **JDK** | 21 | Java 运行环境 | **强制**，不得使用其他版本 |
| **Maven** | 3.9.12 | 构建工具 | 推荐版本，最低 3.8+ |
| **Spring Boot** | 4.0.2 | 微服务框架 | 锁定版本 |
| **Spring Cloud** | 2025.1.0 | 微服务治理 | 锁定版本 |
| **Spring Cloud Alibaba** | 2025.1.0.0 | 服务注册/配置 | 锁定版本 |

### 1.2 强制使用的库

#### 1.2.1 JSON 处理 - Jackson (唯一标准)

**规则**：
- ✅ **必须使用** `com.fasterxml.jackson` 系列库
- ❌ **禁止使用** Gson、Fastjson、Fastjson2

**原因**：
- Spring Boot 默认集成 Jackson，避免序列化冲突
- Jackson 在 CVE 安全性、类型安全性上优于其他方案

**代码示例**：
```java
// ✅ 正确：使用 Jackson 注解
import com.fasterxml.jackson.annotation.JsonIgnore;
import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.databind.ObjectMapper;

public class UserDto {
    @JsonProperty("user_name")
    private String userName;
    
    @JsonIgnore
    private String password;
}

// ❌ 错误：禁止使用 Fastjson
import com.alibaba.fastjson.JSON;  // 禁止导入
```

#### 1.2.2 HTTP 客户端 - HttpExchange (唯一标准)

**规则**：
- ✅ **必须使用** Spring 6 的 `@HttpExchange` 声明式客户端
- ❌ **禁止使用** OpenFeign、RestTemplate、OkHttp、Apache HttpClient

**原因**：
- 原生支持，无需额外依赖
- 与 Spring Cloud 无缝集成，自动负载均衡
- 类型安全，编译时检查

**代码示例**：
```java
// ✅ 正确：使用 HttpExchange
import org.springframework.web.service.annotation.HttpExchange;
import org.springframework.web.service.annotation.GetExchange;
import org.springframework.web.service.annotation.PostExchange;

@HttpExchange("/system")
public interface SystemServiceClient {
    
    @GetExchange("/user/{id}")
    R<UserDto> getUserById(@PathVariable Long id);
    
    @PostExchange("/user")
    R<Void> createUser(@RequestBody UserDto dto);
}

// ❌ 错误：禁止使用 Feign
import org.springframework.cloud.openfeign.FeignClient;  // 禁止
```

#### 1.2.3 对象映射 - MapStruct (唯一标准)

**规则**：
- ✅ **必须使用** MapStruct 进行 PO/DTO 转换
- ❌ **禁止使用** BeanUtils.copyProperties、手动转换、Dozer

**原因**：
- 编译时生成代码，零反射性能损耗
- 类型安全，编译期检查字段匹配
- 支持自定义转换逻辑

**代码示例**：
```java
// ✅ 正确：使用 MapStruct
import org.mapstruct.Mapper;
import org.mapstruct.Mapping;
import org.mapstruct.factory.Mappers;

@Mapper(componentModel = "spring")
public interface UserConverter {
    UserConverter INSTANCE = Mappers.getMapper(UserConverter.class);
    
    @Mapping(source = "userName", target = "name")
    UserDto toDto(UserPo po);
    
    List<UserDto> toDtoList(List<UserPo> poList);
}

// ❌ 错误：禁止使用 BeanUtils
import org.springframework.beans.BeanUtils;  // 禁止使用
UserDto dto = new UserDto();
BeanUtils.copyProperties(po, dto);  // 禁止此操作
```

#### 1.2.4 工具类 - Hutool (间接使用)

**规则**：
- ✅ **允许使用** Hutool 工具包，但**必须通过基础工具类封装后使用**
- ❌ **禁止直接引入** `cn.hutool` 包，禁止在业务代码中直接调用 Hutool 方法

**原因**：
- 统一封装便于版本升级和替换
- 避免 Hutool API 直接散布在业务代码中
- 通过基础工具类提供更符合项目规范的方法签名

**代码示例**：
```java
// ✅ 正确：通过基础工具类使用
import com.han.common.core.util.StringUtils;
import com.han.common.core.util.DateUtils;
import com.han.common.core.util.CollectionUtils;

public class UserService {
    public void process(String text) {
        // 使用项目封装的工具类
        if (StringUtils.isEmpty(text)) {
            return;
        }
        String result = StringUtils.toCamelCase(text);
    }
}

// ❌ 错误：禁止直接使用 Hutool
import cn.hutool.core.util.StrUtil;  // 禁止直接导入
import cn.hutool.core.date.DateUtil;  // 禁止直接导入

public class UserService {
    public void process(String text) {
        if (StrUtil.isEmpty(text)) {  // 禁止直接调用
            return;
        }
    }
}
```

**基础工具类封装示例**：
```java
package com.han.common.core.util;

/**
 * 字符串工具类（封装 Hutool）
 *

 */

    /**
     * 判断字符串是否为空
     */
    public static boolean isEmpty(CharSequence str) {
        return StrUtil.isEmpty(str);
    }
    
    /**
     * 判断字符串是否非空
     */
    public static boolean isNotEmpty(CharSequence str) {
        return StrUtil.isNotEmpty(str);
    }
    
    /**
     * 转换为驼峰命名
     */
    public static String toCamelCase(CharSequence str) {
        return StrUtil.toCamelCase(str);
    }
    
    /**
     * 转换为下划线命名
     */
    public static String toUnderlineCase(CharSequence str) {
        return StrUtil.toUnderlineCase(str);
    }
}
```

## 2. 架构设计规范

### 2.1 A/I/B 三层控制器架构 (强制)

#### 2.1.1 架构定义

han Cloud 采用 **"基类下沉通用逻辑，子类分层定义门面"** 的 A/I/B 模式：

| 层级 | 全称 | 职责 | 路由前缀 | 注解要求 |
|------|------|------|---------|----------|
| **B** | **BaseController** | 持有 Service，实现通用 CRUD 逻辑 | 无 | **不允许** `@RestController` |
| **A** | **AdminController** | 管理端接口，处理 UI 请求 | `/admin` | **必须** `@RestController("Bean名")` + `@PreAuthorize` |
| **I** | **InnerController** | 微服务内部 RPC 调用 | `/inner` | **必须** `@RestController("Bean名")` + `@InnerAuth` |

> 💡 **详细说明**：请查阅 [AIB架构完整实施指南](./AIB架构完整实施指南.md)

#### 2.1.2 标准实现模板

**步骤 1：定义 B 层 (业务基类)**

```java
package com.han.system.controller.base;

import com.han.common.web.controller.BaseController;
import com.han.system.domain.query.SysUserQuery;
import com.han.system.domain.dto.SysUserDto;
import com.han.system.service.ISysUserService;

/**
 * 用户管理业务基类
 * 
 * <p><b>核心方法实现位置：</b>
 * <ul>
 *   <li>list/add/edit/delete → {@link BaseController}
 *   <li>数据权限过滤 → {@link BaseServiceImpl#selectListScope}
 *   <li>多租户注入 → TenantLineInterceptor
 * </ul>
 * 
 * @author han Team
 */
public class BSysUserController 
    extends BaseController<SysUserQuery, SysUserDto, ISysUserService> {
    
    @Override
    protected String getNodeName() {
        return "用户管理";
    }
}
```

**步骤 2：定义 A 层 (管理端接口)**

```java
package com.han.system.controller.admin;

import com.han.common.core.domain.R;
import com.han.common.security.annotation.PreAuthorize;
import com.han.system.controller.base.BSysUserController;
import org.springframework.web.bind.annotation.*;

/**
 * 用户管理 - 管理端接口
 * 
 * @author han Team
 */
@RestController("adminSysUserController")  // 必须指定 Bean 名称
@RequestMapping("/admin/user")
public class ASysUserController extends BSysUserController {
    
    /**
     * 查询用户列表
     * 
     * 🔴 安全要求：必须添加 @PreAuthorize 注解
     */
    @Override
    @GetMapping("/list")
    @PreAuthorize("@ss.hasAuthority(@Auth.SYS_USER_LIST)")
    public R<PageResult<SysUserDto>> list(SysUserQuery query) {
        return super.list(query);
    }
    
    @Override
    @PostMapping("/add")
    @PreAuthorize("@ss.hasAuthority(@Auth.SYS_USER_ADD)")
    public R<Void> add(@RequestBody SysUserDto dto) {
        return super.add(dto);
    }
    
    @Override
    @PostMapping("/edit")
    @PreAuthorize("@ss.hasAuthority(@Auth.SYS_USER_EDIT)")
    public R<Void> edit(@RequestBody SysUserDto dto) {
        return super.edit(dto);
    }
    
    @Override
    @PostMapping("/remove")
    @PreAuthorize("@ss.hasAuthority(@Auth.SYS_USER_DELETE)")
    public R<Void> batchRemove(@RequestBody List<Long> ids) {
        return super.batchRemove(ids);
    }
}
```

**步骤 3：定义 I 层 (内部接口)**

```java
package com.han.system.controller.inner;

import com.han.common.core.domain.R;
import com.han.common.security.annotation.InnerAuth;
import com.han.system.controller.base.BSysUserController;
import org.springframework.web.bind.annotation.*;

/**
 * 用户管理 - 内部调用接口
 * 
 * @author han Team
 */
@RestController("innerSysUserController")
@RequestMapping("/inner/user")
public class ISysUserController extends BSysUserController {
    
    /**
     * 根据 ID 查询用户信息 (内部调用)
     */
    @GetMapping("/{id}")
    @InnerAuth
    public R<SysUserDto> getInfoInner(@PathVariable Long id) {
        return R.ok(baseService.selectById(id));
    }
    
    /**
     * 批量查询用户信息 (内部调用)
     */
    @PostMapping("/batch")
    @InnerAuth
    public R<List<SysUserDto>> listByIds(@RequestBody List<Long> ids) {
        return R.ok(baseService.selectByIds(ids));
    }
}
```

#### 2.1.3 强制性规则

| 规则编号 | 规则内容 | 违规后果 |
|---------|---------|---------|
| **A-001** | B 层**禁止**标注 `@RestController`、`@RequestMapping` | 拒绝合并 |
| **A-002** | A 层所有 Override 方法**必须**添加 `@PreAuthorize` | 安全漏洞，拒绝合并 |
| **A-003** | I 层所有公开方法**必须**添加 `@InnerAuth` | 安全漏洞，拒绝合并 |
| **A-004** | A/I 层必须指定**唯一** Bean 名称 (如 `@RestController("adminSysUserController")`) | 启动失败 |
| **A-005** | 禁止在 Service 层直接注入其他模块的 Service（使用事件驱动或 HttpExchange） | 架构违规 |

### 2.2 领域对象分层规范

#### 2.2.1 POJO 分层定义

han Cloud 使用 **PO → DTO → Query** 三级分层：

```java
// 1. PO (Persistent Object) - 数据库实体
@Data
@TableName("sys_user")
public class SysUserPo extends BaseEntity {
    
    /** 用户 ID */
    private Long userId;
    
    /** 用户名 */
    private String userName;
    
    /** 密码 */
    private String password;
    
    /** 邮箱 */
    private String email;
    
    /** 部门 ID */
    private Long deptId;
}

// 2. DTO (Data Transfer Object) - 数据传输对象
@Data
public class SysUserDto extends SysUserPo {
    
    /** 部门名称（关联字段） */
    private String deptName;
    
    /** 角色 ID 列表（业务扩展字段） */
    private List<Long> roleIds;
    
    /** 密码（传输时忽略） */
    @JsonIgnore
    private String password;
}

// 3. Query (查询对象) - 查询参数对象
@Data
public class SysUserQuery extends SysUserPo {
    
    /** 开始时间（范围查询） */
    private Date beginTime;
    
    /** 结束时间（范围查询） */
    private Date endTime;
    
    /** 部门 ID 列表（数据权限） */
    private List<Long> deptIds;
    
    /** 密码（查询时隐藏） */
    @JsonIgnore
    @ApiModelProperty(hidden = true)
    private String password;
}
```

#### 2.2.2 强制性规则

| 规则编号 | 规则内容 | 示例 |
|---------|---------|------|
| **D-001** | PO 类**必须**继承 `BaseEntity`，使用 `@TableName` 注解 | `@TableName("sys_user")` |
| **D-002** | DTO 类**必须**继承对应的 PO 类 | `SysUserDto extends SysUserPo` |
| **D-003** | Query 类**必须**继承对应的 PO 类 | `SysUserQuery extends SysUserPo` |
| **D-004** | 敏感字段在 DTO/Query 中**必须**标注 `@JsonIgnore` | `@JsonIgnore private String password;` |
| **D-005** | **禁止**在 Query 中定义与 PO 同名但类型不同的字段 | ❌ `private String createTime;` (PO 中是 Date) |
| **D-006** | **禁止**使用 `BeanUtils.copyProperties` 进行对象转换 | 必须使用 MapStruct |

### 3.3 注解使用规范

```java
import com.fasterxml.jackson.annotation.*;

public class SysUserDto {

    private Date createTime;

    @JsonInclude(JsonInclude.Include.NON_NULL)
    private String remark;
}
```

#### 5.1.2 HttpExchange 自动配置（推荐）

**方式一：使用 Spring Boot 自动扫描（推荐）**

```java
package com.han.common.web.config;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.cloud.client.loadbalancer.LoadBalanced;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.reactive.function.client.WebClient;
import org.springframework.web.reactive.function.client.support.WebClientAdapter;
import org.springframework.web.service.annotation.HttpExchange;
import org.springframework.web.service.invoker.HttpServiceProxyFactory;
import org.springframework.context.ApplicationContext;
import org.springframework.core.annotation.AnnotationUtils;

import java.util.Map;

/**
 * HttpExchange 自动配置
 * 
 * <p>自动扫描并注册所有 @HttpExchange 标注的接口
 * 
 * @author han Team
 */
@Configuration
@RequiredArgsConstructor
public class HttpExchangeAutoConfiguration {
    
    private final ApplicationContext applicationContext;
    
    /**
     * 创建支持负载均衡的 WebClient
     */
    @Bean
    @LoadBalanced
    public WebClient.Builder loadBalancedWebClientBuilder() {
        return WebClient.builder();
    }
    
    /**
     * 自动注册 HttpExchange 客户端
     */
    @Bean
    public HttpExchangeClientRegistrar httpExchangeClientRegistrar(
            WebClient.Builder webClientBuilder) {
        
        return new HttpExchangeClientRegistrar(webClientBuilder, applicationContext);
    }
}

/**
 * HttpExchange 客户端注册器
 */
class HttpExchangeClientRegistrar implements org.springframework.beans.factory.config.BeanFactoryPostProcessor {
    
    private final WebClient.Builder webClientBuilder;
    private final ApplicationContext applicationContext;
    
    public HttpExchangeClientRegistrar(WebClient.Builder webClientBuilder, 
                                       ApplicationContext applicationContext) {
        this.webClientBuilder = webClientBuilder;
        this.applicationContext = applicationContext;
    }
    
    @Override
    public void postProcessBeanFactory(
            org.springframework.beans.factory.config.ConfigurableListableBeanFactory beanFactory) {
        
        // 扫描 com.han.api 包下的所有 @HttpExchange 接口
        org.springframework.context.annotation.ClassPathScanningCandidateComponentProvider scanner = 
            new org.springframework.context.annotation.ClassPathScanningCandidateComponentProvider(false);
        
        scanner.addIncludeFilter(new org.springframework.core.type.filter.AnnotationTypeFilter(
            HttpExchange.class));
        
        for (org.springframework.beans.factory.config.BeanDefinition bd : 
             scanner.findCandidateComponents("com.han.api")) {
            
            try {
                Class<?> clientInterface = Class.forName(bd.getBeanClassName());
                HttpExchange annotation = AnnotationUtils.findAnnotation(
                    clientInterface, HttpExchange.class);
                
                if (annotation != null) {
                    // 提取服务名（从路径中推导，如 /system -> han-system）
                    String serviceName = extractServiceName(annotation.value());
                    
                    // 创建客户端
                    Object client = createClient(clientInterface, serviceName);
                    
                    // 注册为 Bean
                    beanFactory.registerSingleton(
                        clientInterface.getSimpleName(), 
                        client
                    );
                }
            } catch (Exception e) {
                throw new RuntimeException("注册 HttpExchange 客户端失败", e);
            }
        }
    }
    
    /**
     * 创建客户端代理
     */
    private <T> T createClient(Class<T> clientInterface, String serviceName) {
        WebClient webClient = webClientBuilder
            .baseUrl("http://" + serviceName)
            .build();
        
        HttpServiceProxyFactory factory = HttpServiceProxyFactory
            .builderFor(WebClientAdapter.create(webClient))
            .build();
        
        return factory.createClient(clientInterface);
    }
    
    /**
     * 从路径提取服务名
     * 
     * @param path 路径（如 /system）
     * @return 服务名（如 han-system）
     */
    private String extractServiceName(String path) {
        String module = path.replaceAll("^/", "");
        return "han-" + module;
    }
}
```

### 5.2 RESTful 路由规范

#### 5.2.1 HTTP 方法约束

han Cloud **仅允许使用 GET 和 POST 两种 HTTP 方法**：

**规则**：
- ✅ **允许使用** `GET` 和 `POST`
- ❌ **禁止使用** `PUT`、`DELETE`、`PATCH` 等其他 HTTP 方法

**原因**：
- 简化 API 设计，降低学习成本
- 避免部分代理服务器/防火墙对 PUT/DELETE 的限制
- 与前端框架兼容性更好

#### 5.2.2 标准路由表

| 操作类型 | HTTP 方法 | 路由格式 | 示例 |
|----------|----------|---------|------|
| **查询列表** | `GET` | `/admin/<resource>/list` | `GET /admin/user/list` |
| **查询详情** | `GET` | `/admin/<resource>/{id}` | `GET /admin/user/1` |
| **新增** | `POST` | `/admin/<resource>/add` | `POST /admin/user/add` |
| **修改** | `POST` | `/admin/<resource>/edit` | `POST /admin/user/edit` |
| **删除单个** | `POST` | `/admin/<resource>/remove/{id}` | `POST /admin/user/remove/1` |
| **批量删除** | `POST` | `/admin/<resource>/remove` | `POST /admin/user/remove` |
| **导出** | `POST` | `/admin/<resource>/export` | `POST /admin/user/export` |
| **导入** | `POST` | `/admin/<resource>/import` | `POST /admin/user/import` |

## 10. 禁止事项清单

### 10.1 技术禁令

| 禁止项 | 原因 | 替代方案 |
|--------|------|------|
| ❌ Fastjson/Gson | 安全漏洞、序列化不一致 | ✅ Jackson |
| ❌ Feign | 已弃用，与 Spring 6 不兼容 | ✅ HttpExchange |
| ❌ BeanUtils.copyProperties | 反射性能差、类型不安全 | ✅ MapStruct |
| ❌ RestTemplate | 已过时 | ✅ HttpExchange |
| ❌ @Autowired 字段注入 | 不利于单元测试 | ✅ 构造器注入 |
| ❌ new Date() | 线程不安全 | ✅ LocalDateTime |
| ❌ SimpleDateFormat | 线程不安全 | ✅ DateTimeFormatter |
| ❌ 直接引入 Hutool | 耐散布在业务代码中 | ✅ 通过 han-common-core 封装 |
| ❌ PUT/DELETE/PATCH 方法 | 代理/防火墙限制 | ✅ 仅使用 GET/POST |

### 10.2 架构禁令

| 禁止项 | 原因 | 正确做法 |
|--------|------|------|
| ❌ B 层标注 @RestController | 破坏架构设计 | 仅在 A/I 层标注 |
| ❌ Service 跨模块直接注入 | 高耦合 | 使用 HttpExchange 或事件驱动 |
| ❌ Controller 直接操作 Mapper | 绕过业务逻辑层 | 必须通过 Service |
| ❌ 在 Query 中重写 PO 字段类型 | 序列化混乱 | 使用不同字段名 |
| ❌ 硬编码权限标识 | 难以维护 | 使用 Auth 常量类 |
| ❌ 业务代码直接调用 Hutool | 难以统一管理 | 通过 han-common-core 工具类 |

### 10.3 安全禁令

| 禁止项 | 原因 | 正确做法 |
|--------|------|------|
| ❌ A 层方法缺少 @PreAuthorize | 安全漏洞 | 所有公开方法必须添加权限校验 |
| ❌ 明文存储密码 | 数据泄露风险 | 使用 BCrypt 加密 |
| ❌ SQL 拼接查询条件 | SQL 注入风险 | 使用 MyBatis-Plus 条件构造器 |
| ❌ 敏感信息写入日志 | 信息泄露 | 使用 @JsonIgnore 隐藏 |
| ❌ 跨域配置 `allowedOrigins("*")` | CSRF 风险 | 明确指定允许的域名 |
