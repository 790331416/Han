# 提炼规则

## 2026-05-15 初始化

- Han 的唯一正式规则文档是 `docs/06-牛马协作总规则.md`，`.codex` 仅作为执行辅助资产。
- 从 VisualFeast 迁移规则时，只保留通用协作机制，不迁移 C++/Qt、A+ 纯视觉路线、阶段计划或项目专属历史。
- Han 正式入口固定为 `README.md`、`docs/`、`sql/`、`deploy/`。
- 涉及文档、SQL、部署结构或 95 发布的变更，必须同步更新对应手册和验证记录。
- 结构整理后必须至少执行对应结构检查脚本。

## 2026-06-03 AIVideo 长任务恢复

- 火山/大模型长任务不能把任务成功与浏览器 SSE 连接绑定；SSE 只能作为实时展示通道，后台任务必须独立完成、独立落库。
- 长任务流式接口必须尽早把 `taskId` 返回给前端，并提供按 `taskId` 查询任务状态的普通 HTTP 接口，页面断线或刷新后才能恢复轮询。
- 对于资产提取这类“AI 先长文本、再结构化入库”的链路，即使结构化解析失败，也要保留 AI 原始输出版本，避免 BOSS 页面只看到“未入库”而丢失排查依据。
