# Han 记忆目录

本目录只保存 Han 当前项目自己的纠错、观察、提炼规则和演化记录。

从 VisualFeast 参考规则时，只迁移通用协作机制，不迁移 VisualFeast 的 C++/Qt、A+ 视觉路线、阶段计划、项目历史日志或业务专属经验。

## 文件用途

- `corrections.jsonl`：记录用户对行为、规则、输出方式的纠正。
- `observations.jsonl`：记录仓库现状、流程痛点、重复问题。
- `learned-rules.md`：把多次出现的问题提炼成新规则候选。
- `evolution-log.md`：记录每次规则工程化变更、结构调整和落地结果。

## 约束

- `.codex/memory` 是协作记忆，不是正式规则入口。
- 可以沉淀候选经验，但新增正式约束必须同步回写 `docs/06-牛马协作总规则.md`。
- 记忆内容不得包含密钥、令牌、客户隐私或未脱敏敏感信息。
