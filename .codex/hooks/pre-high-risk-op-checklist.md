# 高风险操作前检查清单

## 必查项

- 已确认目标环境、盘符、目录、版本、来源、覆盖范围。
- 已确认是否允许联网下载、安装、部署、改配置、启停服务、操作数据库。
- 已确认是否存在备份点、回滚点或替代方案。
- 已确认影响范围、停机窗口、审批方式和观察指标。
- 已确认敏感信息来源合法且不会落入代码、文档、日志或截图。
- 已确认本次动作不是基于猜测执行。
- 涉及 95 时，已确认只能从 `/opt/han/repo/Han` 和 `/opt/han/deploy/{small,medium,full}` 发布。
- 涉及 SQL 时，已确认只使用 `sql/tiers/{small,medium,full}` 或 `sql/upgrades/postgres/` 的正式结构。
- 任一关键信息未明确时，必须先停下来询问。
