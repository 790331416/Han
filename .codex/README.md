# Han Codex 协作资产

本目录承接自进化协作结构，内容已适配 Han 仓库。

## 定位

- `.codex` 是执行辅助资产目录，不是 Han 的正式规则入口。
- Han 的唯一正式规则文档仍然是 `docs/06-牛马协作总规则.md`。
- 若本目录内容与 `AGENTS.md` 或 `docs/06-牛马协作总规则.md` 冲突，以 `docs/06-牛马协作总规则.md` 为准。

## 目录

- `rules/`：按任务类型拆分的执行约束。
- `hooks/`：开始任务、高风险操作前、交付前的检查清单。
- `skills/`：可复用工作模式卡。
- `agents/`：规划、实现、验证角色职责草案。
- `memory/`：纠错、观察、提炼规则和演化记录。

## 使用顺序

1. 先读根级 `AGENTS.md`。
2. 再读 `docs/06-牛马协作总规则.md`。
3. 按任务类型读取本目录中对应的 rules、hooks、skills。
4. 涉及开发、测试、部署、95、SQL 时，同步读取 `docs/02-开发手册.md`、`docs/03-部署手册.md`、`docs/04-测试与验收手册.md`、`docs/05-运维与95环境手册.md` 或 `sql/README.md`。
